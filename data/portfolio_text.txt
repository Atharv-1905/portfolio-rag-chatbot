ML Model Monitoring & Drift Detection
MLOps · Closed-Source · 2026 · In Progress
Architecture
FastAPI serves a monitoring engine that ingests model predictions and reference data in real time.
A React dashboard surfaces drift alerts, data-quality reports, and SHAP-based explanations.
The entire stack is containerised with Docker and orchestrated via CI/CD pipelines.
Detection Methods
Eight statistical detectors cover the full spectrum of drift:
KS Test, Chi-Square, PSI, Wasserstein Distance, Jensen–Shannon Divergence,
CUSUM, PCA-Mahalanobis, and custom multivariate monitors. Each detector
outputs confidence scores with configurable alert thresholds.
